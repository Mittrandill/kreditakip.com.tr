# KrediTakip Uygulaması Dokümantasyonu

## 🎯 Genel Bakış

KrediTakip, kullanıcıların kredi ve finansal yönetimlerini kolaylaştırmak için tasarlanmış kapsamlı bir web uygulamasıdır. Modern teknolojiler kullanılarak geliştirilmiş olan uygulama, kullanıcı dostu arayüzü ve güçlü özellikleriyle öne çıkmaktadır.

## 🏗️ Teknik Altyapı

- **Framework**: Next.js
- **Veritabanı**: Supabase
- **Stil**: Tailwind CSS
- **Kimlik Doğrulama**: Supabase Auth
- **Email Servisi**: MailerSend
- **Dosya Depolama**: Supabase Storage

## 📋 Ana Özellikler

### 1. Kredi Yönetimi
- Kredi kartı ve banka kredisi takibi
- Detaylı ödeme planı görüntüleme
- Otomatik vade hatırlatmaları
- Kredi finansal sağlık analizi
- Gelişmiş raporlama araçları

### 2. OCR Teknolojisi
- PDF banka dökümü analizi
- Otomatik veri çıkarımı
- Akıllı veri işleme
- Çoklu format desteği (PDF, JPG, PNG)

### 3. Bildirim Sistemi
- Email bildirimleri
- Vade hatırlatmaları
- Önemli değişiklik uyarıları
- Özelleştirilebilir bildirim tercihleri

### 4. Güvenlik Özellikleri
- End-to-end şifreleme
- Güvenli veri depolama
- İki faktörlü doğrulama
- KVKK uyumlu veri işleme

### 5. Premium Özellikler
- Sınırsız OCR analizi
- Gelişmiş raporlama
- Reklamsız deneyim
- Öncelikli destek
- API erişimi

## 🗂️ Uygulama Modülleri

### 1. Kullanıcı Arayüzü (/app)
- **/uygulama**: Ana dashboard ve yönetim paneli
- **/krediler**: Kredi listeleme ve yönetimi
- **/bildirimler**: Bildirim merkezi
- **/premium**: Premium özellikler ve abonelik yönetimi

### 2. Kimlik Doğrulama (/auth)
- **/giris**: Kullanıcı girişi
- **/kayit-ol**: Yeni kullanıcı kaydı
- **/sifremi-unuttum**: Şifre sıfırlama
- **/yeni-sifre**: Yeni şifre belirleme

### 3. Bilgi Sayfaları
- **/hakkimizda**: Şirket bilgileri
- **/iletisim**: İletişim formu
- **/blog**: Blog yazıları
- **/sss**: Sıkça sorulan sorular
